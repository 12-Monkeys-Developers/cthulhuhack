Welcome

This guide shows what the Cthulhu Hack system for Foundry VTT offers you as the Game Master: the sheets, the dice rolls, combat from the chat and the tools that help you run the game. It does not replace the rulebook: it explains how Foundry helps you apply the rules.

Contents

  • @@page:options@@: the world settings and what they change at the table.
  • @@page:personnage@@: the investigators' sheet, their resources, equipment and conditions.
  • @@page:adversaire@@: the sheet for creatures and hostile NPCs.
  • @@page:jets@@: the roll dialog, the chat cards and combat.
  • @@page:outils@@: the players manager, search, Fortune and macros.

Versions

This guide describes version 6.2.0 of the system, which requires Foundry VTT V14.

The Cthulhu Hack tab

The system adds a tab to the sidebar, with the Cthulhu Hack icon. It shows the installed version and links to the communities where you can find help: the XII Singes Discord and the Fonderie Discord (French-speaking).

It also holds two buttons for the GM only:

  • Players Manager: reopens the "Players status" window (see @@page:outils@@);
  • Search: looks for a text in the world's journals, actors and items.

Compendiums

The compendiums are grouped in a Cthulhu Hack folder, with an FR subfolder and an EN subfolder: every content exists in both languages.

  • System guide: this guide.
  • Example characters: one ready-to-play investigator per archetype.
  • Archetypes: drop one on a sheet to set it up.
  • Special abilities and Special weapons: the game's standard abilities and weapons.
  • Opponents: the creatures of the core book.
  • Tables: the Out of Action, Temporary Insanity and Shock tables.
  • Out of action, Temporary insanity and Shock: the conditions, to drop on a sheet.
  • Macros: draws on the consequence tables.

By default players cannot see the compendiums; trusted players can browse them and assistants can edit them. This guide can be read by all players.

Compatible modules

  • Dice So Nice: the system provides dice in Cthulhu Hack colours.
  • Token Action HUD Cthulhu Hack (with Token Action HUD Core): rolls saves, resources and damage from the selected token.
