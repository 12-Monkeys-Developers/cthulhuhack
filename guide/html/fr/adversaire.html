L'Adversaire

Les créatures et les PNJ hostiles utilisent la fiche Adversaire. Les cartes du tchat les appellent « Opposant ». Le compendium Adversaires contient les créatures du livre de base, prêtes à l'emploi.

L'en-tête

  • DV : les dés de vie de l'Adversaire ;
  • PV : points de vie actuels et maximum ;
  • PA : points d'armure, déduits automatiquement des dégâts qu'il subit ;
  • Malus : le malus au toucher que subissent les personnages qui l'attaquent ou lui résistent.

Fiche déverrouillée, changer les DV recalcule tout seul les PV maximum (4 par DV, en conservant les blessures déjà subies) et le malus (−1 par DV au-delà du premier).

Les onglets

  • Description : le texte de la créature (ouvert par défaut).
  • Attaques, Capacités, Magie : trois listes, avec un bouton + pour chacune quand la fiche est déverrouillée.

Seuls les attaques, les capacités d'adversaire et les sorts peuvent être déposés sur cette fiche. Un clic droit sur un élément permet de l'éditer ou de le supprimer.

Les attaques

Une attaque se définit par un dé de dégâts, des dégâts fixes et un nombre d'attaques. Quand elle a un dé de dégâts, une icône de dé permet de lancer ses dégâts (dé + dégâts fixes, par exemple « d8 + 2 »). Si un personnage est ciblé, la carte du tchat vous propose de lui appliquer les dégâts.

Une attaque à dégâts fixes seulement n'a pas d'icône de jet : ses dégâts s'appliquent quand vous la choisissez pour une riposte (voir @@page:jets@@).

Capacités et sorts

  • Les capacités d'adversaire gèrent des utilisations limitées comme celles des personnages : clic droit pour Utiliser, Augmenter ou Réinitialiser.
  • Les sorts se lancent avec l'icône de dé (jet de sanité) ; le dé du sort baisse sur un échec.
