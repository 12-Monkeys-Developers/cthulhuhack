Options du système

Les réglages se trouvent dans Paramètres du jeu → Configurer les paramètres → Cthulhu Hack. Ils s'appliquent à tout le monde et seul le MJ peut les modifier. Certains nécessitent de recharger la page, ce que Foundry vous propose à l'enregistrement.

Cthulhu Hack Réédition

Active les règles de la réédition (activé par défaut). Concrètement, dans Foundry :

  • les compétences du personnage sont proposées comme modificateur dans la fenêtre de jet ;
  • avec l'option Adrénaline, les deux jetons du personnage sont présentés comme des jetons de Fortune dans le gestionnaire de joueurs ;
  • la réserve commune de Fortune n'apparaît plus dans le gestionnaire de joueurs.

Option Adrénaline

Ajoute deux jetons sous les sauvegardes de chaque personnage. Un clic sur un jeton le fait passer du joueur au MJ, et inversement. Les jetons sont aussi visibles dans le gestionnaire de joueurs.

Option Fortune et Nb jetons Fortune

Active une réserve de jetons de Fortune commune à la table. Le nombre de jetons restants s'affiche sur toutes les fiches de personnage et se met à jour en direct. Vous le réglez ici, ou directement depuis une fiche (voir @@page:outils@@).

Richesse

  • Pas de gestion de la richesse : la richesse n'apparaît pas sur la fiche.
  • Valeur fixe sous forme d'un dé : la richesse est un dé indiqué sur la fiche, que vous gérez à la main.
  • Gérée comme une ressource : la richesse se lance et diminue sur un échec, comme la Torche ou le Bagou.

Ressource diverse

Saisissez un nom (par exemple « Respect ») pour ajouter une ressource supplémentaire à toutes les fiches. Elle se lance comme les autres ressources. Laissez vide pour ne pas l'utiliser.

Gestion des points de vie

  • Points de vie : la fiche affiche les PV ; le bouton « Appliquer » des cartes de dégâts les retire automatiquement.
  • Dés de vie : la fiche affiche le Dé de vie. Quand un personnage est blessé, la carte de dégâts propose un jet de Dé de vie au lieu de retirer des PV.
  • Points et dés de vie (par défaut) : les deux sont affichés ; les dégâts se retirent des PV.

Afficher le malus d'adversité (Version Réédition)

Quand un joueur cible un Adversaire avant son jet :

  • activé (par défaut) : le malus de l'Adversaire est reporté automatiquement dans la fenêtre de jet et réduit le seuil ;
  • désactivé : le malus s'applique toujours, mais en secret. Les joueurs ne le voient pas : leur carte n'affiche pas le seuil. Vous seul le voyez, dans la fenêtre de jet et dans le détail du seuil sur la carte du tchat (ligne « Malus de l'Opposant (caché) »).

Dégâts simultanés

Quand un personnage réussit une attaque contre un Adversaire ciblé, ses dégâts sont lancés aussitôt, sur la même carte. Désactivé, le joueur les lance lui-même avec le bouton de la carte. Dans les deux cas, un échec laisse la main au MJ pour la riposte (voir @@page:jets@@).

Utiliser l'option d'encombrement (Section 13)

Ajoute un encombrement aux armes et aux objets : taille quand l'objet est équipé, quand il ne l'est pas, et un statut Équipé, Non équipé ou Chez soi. L'onglet Équipement de la fiche affiche l'encombrement actuel, calculé automatiquement, face au maximum que vous saisissez. Les objets laissés chez soi ne comptent pas.

Personnaliser l'apparence

Les couleurs du système sont définies par des variables CSS : un module (par exemple le module d'une campagne) peut les redéfinir pour habiller les fiches et les cartes du tchat à ses couleurs.
