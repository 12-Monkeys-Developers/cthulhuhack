Bienvenue

Ce guide présente ce que le système Cthulhu Hack pour Foundry VTT met à votre disposition en tant que Meneur de jeu : les fiches, les jets de dés, le combat depuis le tchat et les outils pour animer la partie. Il ne remplace pas le livre de règles : il explique comment Foundry vous aide à les appliquer.

Sommaire

  • @@page:options@@ : les réglages du monde et leur effet à la table.
  • @@page:personnage@@ : la fiche des investigateurs, leurs ressources, leur équipement et leurs conditions.
  • @@page:adversaire@@ : la fiche des créatures et des PNJ hostiles.
  • @@page:jets@@ : la fenêtre de jet, les cartes du tchat et le combat.
  • @@page:outils@@ : le gestionnaire de joueurs, la recherche, la Fortune et les macros.

Versions

Ce guide décrit la version 6.2.0 du système, qui nécessite Foundry VTT V14.

L'onglet Cthulhu Hack

Le système ajoute un onglet à la barre latérale, reconnaissable à l'icône Cthulhu Hack. Il affiche la version installée et des liens vers les communautés où trouver de l'aide : le Discord des XII Singes et le Discord de la Fonderie.

Vous y trouvez aussi, réservés au MJ, deux boutons :

  • Gestionnaire de joueurs : rouvre la fenêtre « Statut des joueurs » (voir @@page:outils@@) ;
  • Recherche : cherche un texte dans les journaux, les acteurs et les objets du monde.

Les compendiums

Les compendiums sont rangés dans un dossier Cthulhu Hack, avec un sous-dossier FR et un sous-dossier EN : chaque contenu existe dans les deux langues.

  • Guide du système : ce guide.
  • Prétirés : un investigateur prêt à jouer par archétype.
  • Archétypes : à déposer sur une fiche pour l'initialiser.
  • Capacités spéciales et Armes spéciales : les capacités et armes standard du jeu.
  • Adversaires : les créatures du livre de base.
  • Tables aléatoires : les tables Hors jeu, Folie passagère et Choc.
  • Hors jeu, Folie passagère et Choc : les conditions, à déposer sur une fiche.
  • Macros : tirages sur les tables de conséquences.

Par défaut, les joueurs ne voient pas les compendiums ; les joueurs de confiance peuvent les consulter et les assistants les modifier. Le guide, lui, est consultable par tous les joueurs.

Modules compatibles

  • Dice So Nice : le système fournit des dés aux couleurs de Cthulhu Hack.
  • Token Action HUD Cthulhu Hack (avec Token Action HUD Core) : lance sauvegardes, ressources et dégâts depuis le token sélectionné.
